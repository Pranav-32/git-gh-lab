macOS · Steps 1 + 2

macOS setup

Terminal→Homebrew · installs tools for you→gitgh
1

Open Terminal

⌘ Cmd+Space→terminal→Return
2

Install Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Enter your Mac password when asked · typing shows nothing, that’s normal · takes 5–10 min

3

Add Homebrew to your PATH

Apple M-chip only
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Check: Apple menu → About This Mac → Chip: Apple M… · Intel Mac? Skip this step.

4

Install Git + GitHub CLI

brew install git gh
5

Quit & reopen Terminal

⌘+Q
?

No Homebrew? Git: run xcode-select --install · GitHub CLI: download the .pkg from cli.github.com. Then go to page 6.

Linux · Steps 1 + 2

Linux setup

A

Ubuntu · Debian · Mint

1

Open Terminal

Ctrl+Alt+T
2

Install Git

sudo apt update && sudo apt install git -y
3

Add GitHub’s package source

copy the whole box
sudo mkdir -p -m 755 /etc/apt/keyrings
wget -qO- https://cli.github.com/packages/githubcli-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null
sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" \
  | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null
4

Install GitHub CLI

sudo apt update && sudo apt install gh -y
B

Other distros · one line

FEDORA

sudo dnf install git gh

ARCH

sudo pacman -S git github-cli

OPENSUSE

sudo zypper install git gh
i

The sudo password is your login password · typing shows nothing. Then go to page 6.

All systems · Steps 3 + 4

Verify, set up & log in

03

Check it works

in a new terminal
git --version
gh --version
$ git --version
git version 2.x.x   ✓
$ gh --version
gh version 2.x.x    ✓
!

“not recognized” / “not found”? Close the terminal, open a new one and try again.

04

Tell Git who you are

once per laptop
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main

Use your name and the same email as your GitHub account.

05

Connect to GitHub

use ↑ ↓ and Enter to choose
$ gh auth login
